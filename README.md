# Fashionyapa — Premium Storefront Demo

A Next.js 14 / React storefront concept for Fashionyapa using a blush, cream and plum visual system and supplied product imagery.

## Run locally

1. Install Node.js 18.17+ (Node 20 LTS recommended).
2. In this folder run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.
4. Run `npm run build` before deploying.

## Included in the demo
- Responsive storefront, navigation, search, wishlist interaction and shopping bag drawer.
- Category tiles: Hair Accessories, Baddie Jewels and Viral Combos.
- Featured product cards, FAQ and brand/about section.
- Social links for Fashionyapa Instagram and YouTube.
- Footer credit linking to https://upfigure.in/.

## Before production launch
- Replace demo product names, prices, discounts and catalogue data with the client's approved catalogue.
- Confirm shipping threshold/fees, COD advance amount, delivery timelines, returns/refunds, privacy and terms with the client.
- Add genuine customer reviews only after the client supplies/approves them; no fabricated reviews are included.
- Connect backend/database, order management, payment gateway and server-side payment verification.
- Implement and test the ₹100 COD advance flow, COD eligibility, failed/cancelled payments, order confirmation, shipping integration and transactional messages.
- Run `npm install`, `npm run build`, test mobile layouts and all controls, and deploy to the chosen hosting provider.

This is a frontend approval demo, not a live transactional store. The build could not be verified in this environment because dependency installation timed out.
